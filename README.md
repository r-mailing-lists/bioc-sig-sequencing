# bioc-sig-sequencing

Bioconductor SIG on high-throughput sequencing

Automated mbox archive. Updated daily via GitHub Actions.

## Structure

- `raw/` - Monthly .mbox files downloaded from [https://stat.ethz.ch/pipermail/bioc-sig-sequencing/](https://stat.ethz.ch/pipermail/bioc-sig-sequencing/)
- `processed/` - Structured JSON output from rmail-parser
- `meta.json` - List statistics

## Viewer

Browse these archives at [archives.rstats.dev](https://archives.rstats.dev/lists/bioc-sig-sequencing/)
